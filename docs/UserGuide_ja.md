# かんたんルーレット 使い方

[English](UserGuide.md) | 日本語

かんたんルーレットは、登録したアイテムの中から、ルーレットを回して 1 つを選ぶアプリです。
アイテムごとに当たりやすさ（Weight）を変えたり、当たったアイテムを次から外したりできます。

- [1. はじめて使うとき](#1-はじめて使うとき)
- [2. 画面と操作](#2-画面と操作)
- [3. 困ったとき](#3-困ったとき)
- [4. アンインストール](#4-アンインストール)
- [お問い合わせ](#お問い合わせ)

## 1. はじめて使うとき

### 起動する

スタート メニューから「かんたんルーレット」を起動します。
はじめて起動したときは、「Roulette1」〜「Roulette9」の 9 個の空のリストがあります。

画面は、左から次の 3 つに分かれています。

| 場所 | 内容 |
| --- | --- |
| 左 | ルーレット |
| 中央 | 選んでいるリストのアイテム（「詳細」タブと「テキスト」タブ）と、**スタート** ボタン |
| 右 | リストの選択と操作、アイテムの操作、「データ」タブと「その他」タブ |

### ルーレットを回してみる

1. 中央の「テキスト」タブを押します。
2. 選びたいものを、1 行に 1 つずつ入力します。ほかのアプリからコピーして貼り付けることもできます。

   ```
   カレー
   ラーメン
   寿司
   ```

3. **スタート** ボタンを押します。ルーレットが回り、止まると「🎉 結果」に当たったアイテムが表示されます。
4. **OK** を押して閉じます。

入力した内容は自動で保存されます。保存のための操作はありません。

## 2. 画面と操作

### ルーレットを回す

次のどれかで回します。回っている間は、もう一度回すことはできません。

- **スタート** ボタンを押す
- ルーレットの円の中をクリックする
- Space キーか Enter キーを押す（文字の入力中を除く）

チェックを外したアイテムは、ルーレットに表示されず、抽選から外れます。

### アイテムを登録する（「詳細」タブ）

アイテムを表の形で編集します。1 つのリストに、最大 30 個まで登録できます。
タブの右に、登録している数が「5/30」のように表示されます。

| 項目 | 説明 |
| --- | --- |
| 有効 | チェックを外すと抽選対象から一時的に除外されます。有効なアイテムが 2 個以下のときは、それ以上外せません |
| 名前 | ルーレットに表示する名前。名前が空のアイテムは保存されません |
| Weight | Weight は 1～5 の範囲で指定します。値が大きいほど選ばれやすくなります（はじめは 1）。Weight が 2 のアイテムは、1 のアイテムの 2 倍当たりやすくなります |

表の下には、30 個に達したときは「最大30件です」、同じ名前のアイテムがあるときは「重複: 〜」と表示されます。
同じ名前のアイテムがあってもそのまま使えますが、ルーレットでは見分けられません。

### アイテムを登録する（「テキスト」タブ）

1 行に 1 つずつ、「名前,Weight」の形で入力します。Weight を省略すると 1 になります。

```
カレー,3
ラーメン
寿司,2
```

- Weight に 1〜5 以外の数を書くと、1 か 5 に直して使います。
- 31 行目以降は読み込みません。
- 「テキスト」タブで書き換えると、そのリストの「有効」のチェックは、同じ名前のアイテムのものを引き継ぎます。

### アイテム操作

右の「アイテム操作」のボタンは、「詳細」タブの表に対して働きます。

| ボタン | 説明 |
| --- | --- |
| アイテム追加 | 表の最後に「新しいアイテム」を追加します |
| 選択削除 | 表で選んでいるアイテムを削除します |
| 選択を上へ / 選択を下へ | 表で選んでいるアイテムを、1 つ上・下へ移します |
| 一覧ソート | アイテムを名前の順に並べ替えます |
| 一覧シャッフル | アイテムの順番をばらばらにします |

### リストを使い分ける

右上のコンボボックスで、使うリストを選びます。その右に、何番目のリストかが表示されます。
アイテムと「当たったら除外」の設定は、リストごとに保存されます。

| 項目 | 説明 |
| --- | --- |
| クリア | 選んでいるリストのアイテムを、確認のあと、すべて削除します。元に戻せません |
| （保存の状態） | 「保存中」「保存済み」などと表示されます。「保存失敗」のときは、[困ったとき](#保存できませんでしたと表示される) を見てください |
| 当たったら除外 | ONにすると、当選した項目が次回以降の抽選から自動的に除外されます（除外したアイテムは、「有効」のチェックが外れます）。有効なアイテムが残り 1 個になると、それ以上は除外しません |
| グループ名の入力欄と **変更** | リストの名前を入力し、**変更** を押すと保存されます。**変更** を押すまでは「未保存」と表示されます |
| リセット | 名前の入力欄を「New Roulette」にします。保存するには **変更** を押します |
| リストを追加 | 新しい空のリスト「New Roulette」を追加します |
| リストを削除 | 選んでいるリストを、確認のあと削除します。元に戻せません。リストが 1 つだけのときは削除できません |
| リストを複製 | 選んでいるリストを、アイテムごとコピーします |
| リストを上へ / リストを下へ | リストの並び順を変えます |

### データ（CSV、バックアップ、OneDrive 同期）

右下の「データ」タブにあります。

**CSV（選択中のリスト）**

| ボタン | 説明 |
| --- | --- |
| CSVエクスポート | 選んでいるリストのアイテムを CSV ファイルに保存します。1 行目は「アイテム名,Weight」で、Excel などで開けます |
| CSVインポート | CSV ファイルを読み込み、選んでいるリストのアイテムと置き換えます。今のアイテムがあるときは、確認のあと置き換えます |

CSV ファイルは、1 行に 1 つずつ「名前,Weight」の形で書きます。1 行目の「アイテム名,Weight」は無くてもかまいません。
文字コードは、UTF-8・UTF-16・Shift_JIS のどれでも読み込めます。

**バックアップ（全リスト）**

| ボタン | 説明 |
| --- | --- |
| バックアップ保存 | すべてのリストとアイテムを 1 つのファイルに保存します |
| バックアップ復元 | バックアップファイルから、すべてのリストとアイテムを復元します。今のデータは置き換わります（確認のあと置き換えます。元に戻せません） |

PC を買い替えるときや、アプリを入れ直す前には、**バックアップ保存** でファイルを作っておいてください。

**OneDrive 同期**

PC で OneDrive を使っている場合だけ表示されます。OneDrive フォルダーを通じて、ほかの PC とリストを同期できます。

- アイテムを変更すると、そのリストが自動で OneDrive フォルダーに保存されます。
- 起動したときは、選んでいるリストだけを OneDrive フォルダーから読み込みます。
- **今すぐ同期** を押すと、すべてのリストを同期します。リストごとに、新しく変更された方のデータが使われます。
- 同期されるのは、リストの名前、アイテム、「当たったら除外」の設定です。どちらの PC にもあるリストどうしで同期し、ほかの PC で追加したリストは追加されません。
- 状態は「同期待機」「同期中」「同期済み」「同期失敗」のように表示されます。

ほかの PC で変更したあとは、**今すぐ同期** を押してから使うと確実です。

### その他

右下の「その他」タブにあります。

| ボタン | 説明 |
| --- | --- |
| ウィンドウサイズをリセット | ウィンドウを、画面に合わせたはじめの大きさに戻します |
| 常に最前面表示 | オンにすると、ほかのウィンドウより前に表示し続けます |

ウィンドウは、次に起動したときも、前回の大きさと位置で開きます。

### アプリの情報

「その他」タブにあります。

| 項目 | 説明 |
| --- | --- |
| このアプリについて | アプリのバージョンなどを表示します |
| ライセンス情報 | アプリが使用しているソフトウェアのライセンスを表示します |
| 使い方 | このページ（使い方ガイド）を Web ブラウザーで開きます |

## 3. 困ったとき

### スタート ボタンが押せない

ルーレットが回っている間と、有効なアイテムが 1 つも無いときは押せません。
アイテムを登録するか、「詳細」タブで「有効」にチェックを入れてください。

### アイテムのチェックを外せない

有効なアイテムが 2 個以下のときは、チェックを外せません。
ほかのアイテムを有効にするか、アイテムを追加してください。

### 「当たったら除外」で外れたアイテムを戻したい

「詳細」タブで、そのアイテムの「有効」にもう一度チェックを入れます。

### アイテムを 31 個以上登録したい

1 つのリストに登録できるのは 30 個までです。リストを分けて使ってください。

### 「保存できませんでした」と表示される

ウィンドウの上部に赤い帯が出て、保存できなかった内容が表示されます。
アプリを再起動してから、もう一度操作してください。
続く場合は、帯の **ログを開く** で記録を開き、[お問い合わせ](#お問い合わせ) から内容を添えてお知らせください。

### 「OneDrive 同期」が表示されない

PC で OneDrive が設定されていないと表示されません。
Windows の OneDrive アプリにサインインしてから、かんたんルーレットを起動し直してください。

### ほかの PC に同期されない

- OneDrive アプリが同期を終えているか、タスクバーの OneDrive のアイコンで確かめてください。オフラインのときは、接続後に反映されます。
- 反映されたあと、かんたんルーレットで **今すぐ同期** を押してください。
- 「同期失敗」と表示されたときは、少し待ってから **今すぐ同期** を押し直してください。

### ほかの PC にデータを移したい

1. 元の PC で、「データ」タブの **バックアップ保存** でファイルを保存します。
2. そのファイルを新しい PC にコピーします。
3. 新しい PC で、**バックアップ復元** でそのファイルを選びます。

## 4. アンインストール

スタート メニューで「かんたんルーレット」を右クリックし、「アンインストール」を選びます。

- アンインストールすると、PC に保存しているリストとアイテム、設定、エラーの記録が削除されます。
- OneDrive フォルダーのファイル（`Apps\AppRoulette`）は削除されません。要らない場合は、エクスプローラーで削除してください。
- 自分で保存した CSV ファイルやバックアップファイルは削除されません。
